# ARG 游戏开发工作流（提案 v1）

> 拆解自：银河电灯（四步法）、PromptLab（AI量产模式）、arg-designer（五阶段法）
> 待与用户商定后定稿

---

## 一、拆解：标杆们的工作流

### 银河电灯四步法
```
① 自己构思剧本（核心诡计、悬疑推理 → 人工）
② 用AI检查剧本（找逻辑硬伤 → AI辅助）
③ 手工列页面清单（每页信息、关键词、推进逻辑 → 人工）
④ AI转换网页代码（拿模板照画，逐步调整 → AI执行）
```

### PromptLab 一人量产模式
```
人 = 设计师：结构设计、难度调整、导引线设计、发布设计
AI = 制作组：谜题量产、暗号、伪文书、日记断片、新闻文本
```

### 共同结论
- **「什么是有趣的」必须人工判断** — AI 帮写代码，不帮想故事
- **AI 沟通成本高** — 银河电灯花了三周和 AI 磨合网页
- **断片艺术** — ARG 天然适合 AI 量产（伪文档/日记/新闻）

## 二、我们的优势（比银河电灯更强的地方）

| 优势 | 说明 |
|------|------|
| 我会主动搜竞品 | 每次选题先调研同类游戏，避免撞车 |
| 我们有工具集合 | 脚本生成/文案改写/剪辑/发布全链路现成 |
| 用户是内容博主 | 懂小红书/B站生态，自带推广渠道 |
| 我全程参与 | 不需要「反复询问 AI 听不懂人话」，我可以直接干活 |

## 三、提议工作流（六阶段）

### 阶段 0：选题与竞品调研
- 用户给选题方向
- 我搜索市面类似游戏（中文网页ARG / 国外ARG / 同类题材）
- 输出：《竞品调研报告》——已有作品、撞车风险、差异化机会

### 阶段 1：世界观与剧本（人工为主）
- 用户构思：核心诡计、悬疑点、结局方向
- 我配合：世界观文档、角色设定、时间线整理
- 我检查：逻辑硬伤、伏笔回收、规则一致性

### 阶段 2：谜题设计（人机协作）
- 用户定：哪些谜题「有趣」、难度梯度、惊吓点
- 我量产：密码学谜题（凯撒/维吉尼亚/Base64）、伪文档（日记/新闻/报告）、隐藏信息（图片隐写/音频频谱/零宽字符）
- 输出：《谜题清单》——每个谜题的位置、解法、提示文案

### 阶段 3：页面清单（人工为主）
- 拆解：每页的信息、关键词跳转逻辑、进度数字
- 明确：入口页（Trailhead）伪装成什么网站
- 规划：真结局/假结局/彩蛋页

### 阶段 4：网页制作（AI执行）
- 我用 HTML/CSS/JS 逐个实现页面
- 模拟真实网站质感（2005年官网/论坛/博客风格）
- 每页带进度数字标记
- 关键词搜索框推进

### 阶段 5：测试与发布
- 我自测：所有谜题链路、死锁检查、手机适配
- 内测：用户试玩反馈
- 发布：GitHub Pages 托管
- 推广：结合用户的小红书账号发预告

## 四、每游戏必备产出物

```
游戏开发日志.md     ← 每次决策、进度、灵感记录
世界观设定.md       ← 故事背景、角色、规则
谜题清单.md         ← 所有谜题与解法
竞品调研.md         ← 类似游戏分析
页面清单.md         ← 每页内容与跳转逻辑
```

## 五、待商定问题

1. **分工边界**：剧本部分你想自己写到什么程度？还是给我大纲我来扩写？
2. **谜题难度**：面向「新手向」还是「硬核玩家」？银河电灯走新手向（2-3小时通关）
3. **发布节奏**：一次做完发布，还是分章节连载？
4. **工具**：网页直接用纯HTML/CSS/JS（零成本托管GitHub Pages），还是需要什么特殊功能？
